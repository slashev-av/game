# Побег из комнаты

Браузерная игра с видом сверху: персонаж бегает по тёмной комнате, обыскивает предметы, находит спрятанные ключи и выходит через дверь. Автор общается на русском — отвечать и писать тексты интерфейса и комментарии в коде тоже на русском.

## Запуск

Двойной клик по `index.html`. Сборки, зависимостей и сервера нет, и так должно оставаться:
игра обязана работать по `file://`, поэтому **никаких ES-модулей (`import`/`export`) и `fetch` локальных файлов**.

Node.js на машине не установлен — проверять код можно только в браузере.

## Файлы

- `index.html` — разметка: HUD (уровень, ключи, «чутьё», время), `<canvas id="game">` 800×544, оверлей меню/победы, строка `#monster-info` с описанием монстра комнаты.
- `style.css` — оформление страницы и HUD. Холст масштабируется по ширине окна.
- `game.js` — вся игра в одном IIFE, разделы помечены комментариями `// ---------- ... ----------`.

## Как устроена игра

- **Карта**: сетка 25×17 тайлов по 32 px. `grid[y][x]` = `FLOOR | WALL | DOOR`.
- **Генерация** (`generateLevel`): внешние стены + случайные перегородки (кольцо вдоль внешних стен всегда свободно), дверь на внешней стене, старт далеко от двери, предметы-тайники. Заливкой проверяется, что дверь и каждый предмет достижимы; иначе попытка повторяется.
- **Тайники** (`containers`): типы `chest, barrel, crate, vase, shelf`; это непроходимые тайлы. В части из них лежат ключи (`hasKey`). Обыск — удерживать E/Пробел рядом `SEARCH_TIME` секунд.
- **Дверь**: непроходима, пока не собраны все ключи; вход в её тайл = победа на уровне.
- **Туман**: канвас 25×17 (пиксель на тайл), растягивается со сглаживанием. Тайл освещён, если он в радиусе `lightRadius` и до него есть прямая видимость (`hasLineOfSight`); виденные тайлы остаются притемнёнными, невиденные — чёрные.
- **«Чутьё»**: шкала в HUD заполняется по мере приближения к ближайшему ненайденному ключу.
- **Монстры** (раздел `// ---------- Монстры ----------`, описания в константе `MONSTERS`): в каждой комнате ровно один, типы не повторяются, пока не встретятся все шесть (`monsterBag`); при перезапуске комнаты по R монстр тот же (`monsterByLevel`). После касания игрока монстр переносится вдаль (`placeMonster`).
  - `ghost` Призрак — летит сквозь стены, касание возвращает игрока на старт.
  - `goblin` Гоблин-вор — бродит, а когда у игрока есть ключи, гонится; отбирает ключ и перепрятывает (`hideKey`).
  - `slime` Слизень — оставляет слизь (`slime[y][x]`, замедляет до 40%), касание — прилипание.
  - `shadow` Тень — рядом с ней свет слабее (`currentLight`), касание ослепляет на 5 с и стирает `seen`. Глаза рисуются поверх тумана.
  - `poltergeist` Полтергейст — игрока не трогает; летает сквозь стены, закрывает обысканные предметы и перекладывает ключи.
  - `spider` Паук — гонится, плетёт паутину (`webs`, держит 1.3 с), кусает (оглушение 2 с).
  - Ходячие монстры идут по полю расстояний `pathDist` (поиск в ширину от игрока, пересчитывается каждый кадр). Эффекты на игроке: `player.stun`, `player.blind`.
  - Отладка: `index.html#spider` (любой ключ из `MONSTERS`) принудительно ставит нужного монстра.
- **Сложность**: уровень N → ключей `min(2+N, 7)`, предметов больше, радиус света меньше (не ниже 3.2 тайла), монстр быстрее на 4% за уровень (не более +40%).
- **Рекорды**: лучшее время по каждому уровню в `localStorage` (`escape-best-<уровень>`).
- **Графика и звук**: всё рисуется примитивами canvas, звуки — WebAudio-осцилляторы. Внешних ассетов нет.

## Соглашения

- Клавиши читать через `e.code` (а не `e.key`), иначе управление ломается в русской раскладке.
- Настройки баланса — константы в начале `game.js`.
- Статичная карта (пол, стены) рисуется один раз в `renderMap()` на отдельный канвас; при изменении `grid` её нужно перерисовать.

## Состояние проекта

- 2026-10-07: создана первая играбельная версия (всё перечисленное выше). Проверено в headless Edge: уровень запускается без ошибок JS, карта и туман рисуются. Сам геймплей (обыск, сбор ключей, выход через дверь) вручную ещё никто не проходил.
- Для проверки без Node можно запускать `msedge.exe --headless --screenshot=... file:///G:/My%20Game/index.html`.
- 2026-10-07: добавлены монстры (по одному на комнату, 6 типов). Проверено в headless Edge прогоном ~2.5 минут игры со случайными нажатиями на каждого монстра: ошибок JS нет, эффект каждого срабатывает. Баланс (скорости, длительности) живым игроком не проверялся. Приём для такого прогона: тестовая страница подменяет `requestAnimationFrame` и сама крутит кадры в цикле.
- Git-репозиторий не инициализирован.
